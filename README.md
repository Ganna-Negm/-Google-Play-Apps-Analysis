# 📊 Google Play Apps Analysis: Performance, User Behavior & Insights

## 📌 Overview
This project presents a comprehensive analysis of Google Play Store applications using Power BI.  
It explores app performance, user ratings, installs, and user sentiment to uncover meaningful insights.

---

## 🎯 Objectives
- Understand app market trends  
- Analyze user ratings and installs  
- Evaluate app performance across categories  
- Explore user sentiment and behavior  

---

## 📊 Dashboard Pages

### 🟢 1. Overview
Provides a general view of the dataset including total apps, installs, ratings, and category distribution.

### 🔵 2. App Performance
Analyzes ratings, installs, and category performance to identify top and low-performing segments.

### 🟡 3. User Behavior & Sentiment Analysis
Examines user feedback using sentiment analysis to understand real user experience beyond ratings.

---

## 💡 Key Insights
- Most apps are free and dominate the market  
- Average rating is around 3.6 indicating moderate user satisfaction  
- Some categories generate significantly higher installs  
- High ratings do not always guarantee positive user sentiment  
- User feedback is often subjective and experience-driven  

---

## 🛠️ Tools Used
- Power BI  
- Excel  
- Python (for sentiment analysis)
